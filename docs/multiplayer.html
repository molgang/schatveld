Schatveld — Multiplayer

The full version, on a local server & the Python "brain" · Minecraft 1.21.10
The server is already running on this computer (server + brain + bridge). Just connect from Minecraft. Address: localhost

▶ Connect & play

  1. Open the Modrinth App → profile chemlab → Play.
  2. In the menu: Multiplayer. The server Schatveld (localhost) is already in your list — click it and Join. (Or Direct Connection → localhost.)
  3. You spawn on the marsh. Press T and run /function schatveld:menu, then click a role.
  4. Archaeologist → you get the Metal Detector + Shovel. Right-click the ground → reading 0–100. Dig → your find (with the € payout).
Language: Options → Language — English (default) + Deutsch, Français, Русский, Español, Português (BR), 简体中文, 日本語, Nederlands.

💶 What multiplayer adds (the "brain")

Everything from singleplayer plus the economy — all computed by the Python brain, shared across the world:

  • € payouts for every find, and the Schatzregal: significant finds become state property and pay a finder's fee — but only if you dug legally (with a Nachforschungsgenehmigung permit). Illegal digging = Raubgrabung, and the find is confiscated.
  • Landesmuseum — the first time you find each of the 13 kinds, you get an Erstfund bonus (a collection to complete, n/13).
  • Reputation ranks — Sondengänger → Feldforscher → Denkmalpfleger → Landesarchäologe.
  • Farmer & Police scoring — crop rotation bonuses/penalties, pesticide-buffer rules, and fines.
